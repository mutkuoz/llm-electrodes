How it works

Every MLP neuron writes along one fixed direction of the model's residual stream: its column of the layer's down_proj weight. An electrode adds a push along that direction after its layer, at every token. A negative dose suppresses the neuron, a positive one boosts it.

Doses are measured in units of the layer's typical residual size, so −0.5 means the same strength at layer 3 and at layer 30. Nothing is trained: the weights stay untouched and the push disappears when you disarm it.

This is exactly what PEFT's activation steering adapters do. check_parity.py shows neurollm producing the same tokens as PEFT, while letting every channel of a batch carry its own doses, which is what makes Compare and Ladder run in one pass.

Reading the cockpit

Probe field
All 32 layers × 9,216 MLP neurons as live tissue; bright means firing. Click any spot to plant an electrode on that neuron.
Personas
Keys that arm a known recipe. Hover one to read what it does. Arm several and their pushes add up.
Dose
One knob per persona or electrode. Drag, scroll or use the arrow keys. Click the number to type an exact value; double-click to reset.
Channels
The answers, one lane per channel. Each token is tinted by how hard the watched neuron fired on it.
Scope
The watched neuron's firing, token by token, one trace per channel.
Mode
Chat keeps a conversation. Compare runs the plain model next to the steered one. Ladder runs 0 to 100% of your doses at once.
Sampling
Temperature, max tokens, top-p, top-k and repetition. Temperature 0 is greedy, so channels differ only by the steering.
Save as persona
Turns whatever is dialed in into a new persona key and a file in personas/.

Add a persona

Found a neuron that does something strange? Save it from the cockpit and it lands in personas/ as one small file. Check it with python personas.py, commit it and open a pull request. CONTRIBUTING.md explains how to describe it so others can reproduce it.

Everything runs on your own machine. You need a GPU with about 9 GB of free memory.
